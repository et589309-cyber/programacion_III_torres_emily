# 💻 Programación III

**Autor:** Emily Alejandra Torres Toapanta

## 📖 Descripción

Repositorio correspondiente a la materia **Programación III**, donde se desarrollarán diferentes actividades y proyectos relacionados con el desarrollo web.

## 🚀 Tecnologías

### 🌐 HTML

Permite crear la estructura y organización del contenido de una página web.

### 🎨 CSS

Se utiliza para diseñar y personalizar la apariencia de las páginas web.

### ⚡ JavaScript

Permite agregar lógica, interacción y comportamiento dinámico a las aplicaciones web.

### 🔷 TypeScript

Extiende JavaScript incorporando tipado y herramientas que permiten desarrollar aplicaciones más organizadas y escalables.

### 🦁 NestJS

Framework basado en Node.js y TypeScript utilizado para desarrollar aplicaciones y APIs en el backend.

### ⚛️ ReactJS

Biblioteca de JavaScript utilizada para crear interfaces web mediante componentes reutilizables e interactivos.

## 🎯 Objetivo

Aplicar los conocimientos adquiridos en la materia mediante el desarrollo de aplicaciones web utilizando tecnologías frontend y backend.
